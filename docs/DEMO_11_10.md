# 11/10 Demo Path

This demo path proves the release-critical properties of FamilyClaw without using private Layer B data. It is intentionally generic and should run with placeholder agents only.

The goal is not to show every feature. The goal is to prove the foundations:

1. Layer B stays private.
2. Tests and feature matrix pass.
3. Continuity benchmark passes.
4. Gateway starts.
5. Health and readiness work.
6. Inbound messages preserve origin.
7. Replies route to the correct conversation or fallback target.
8. Durable state survives restart.
9. Memory can be recalled after restart.
10. Experimental areas are labeled honestly.

## 0. Start clean

Use a temporary private runtime directory outside the repository:

```bash
export FC_PRIVATE_ROOT="/tmp/familyclaw-private-demo"
rm -rf "$FC_PRIVATE_ROOT"
mkdir -p "$FC_PRIVATE_ROOT/profiles/agent_a" "$FC_PRIVATE_ROOT/data" "$FC_PRIVATE_ROOT/backups"
```

Create a placeholder profile:

```bash
cat > "$FC_PRIVATE_ROOT/profiles/agent_a/SOUL.md" <<'EOF'
I am agent_a, a generic FamilyClaw demo being.
I exist only for public Layer A validation.
EOF

cat > "$FC_PRIVATE_ROOT/profiles/agent_a/calibration.json" <<'EOF'
{
  "profile": "demo",
  "notes": "generic placeholder only"
}
EOF
```

Create a minimal runtime config:

```bash
cat > "$FC_PRIVATE_ROOT/familyclaw.toml" <<'EOF'
[agent]
name = "agent_a"

[channel]
kind = "telegram"
reply_target = "local-demo"

[channel.telegram]
token = "placeholder-token"
channel_id = "local-demo"

[provider]
kind = "openai"
model = "openai/gpt-4.1-mini"
api_key = ""

[memory]
retention_hours = 168
max_working_memories = 500
compaction_threshold = 0.3

[security]
profile = "supervised"
gateway_token = "local-demo-token"
EOF
```

This directory is Layer B-shaped, but it contains no real private data.

## 6. Start the gateway

```bash
FAMILYCLAW_GATEWAY_ADDR=127.0.0.1:8787 \
FAMILYCLAW_CONFIG="$FC_PRIVATE_ROOT/familyclaw.toml" \
FAMILYCLAW_PROFILE_DIR="$FC_PRIVATE_ROOT/profiles" \
FAMILYCLAW_DATA_DIR="$FC_PRIVATE_ROOT/data" \
FAMILYCLAW_GATEWAY_TOKEN=local-demo-token \
cargo run -p familyclaw-gateway -- serve
```

Expected:

- Gateway starts.
- It does not print private secrets.
- It loads only runtime-provided private paths.
- If no real provider endpoint is configured, the agent may run without text replies. That is acceptable for this generic demo path.

## 7. Check health and readiness

In another shell:

```bash
curl -fsS http://127.0.0.1:8787/healthz
curl -fsS http://127.0.0.1:8787/readyz
```

Expected:

- `/healthz` succeeds when the process is alive.
- `/readyz` succeeds when runtime readiness conditions are met.

## 8. Exercise supervised inbound

Use `/inject` with a bearer token:

```bash
curl -X POST http://127.0.0.1:8787/inject \
  -H "Authorization: Bearer local-demo-token" \
  -H "Content-Type: application/json" \
  -d '{"sender":"operator","conversation":"demo-conversation-a","body":"Remember this demo checkpoint."}'
```

Then inject a second conversation:

```bash
curl -X POST http://127.0.0.1:8787/inject \
  -H "Authorization: Bearer local-demo-token" \
  -H "Content-Type: application/json" \
  -d '{"sender":"operator","conversation":"demo-conversation-b","body":"This is a different conversation."}'
```

Expected:

- Requests are accepted only with the correct token.
- Per-message origin is preserved.
- Replies route to the conversation when origin is available.
- Static `FAMILYCLAW_REPLY_TARGET` is fallback behavior, not the primary route for originated messages.

## 9. Verify durable restart behavior

Stop the gateway cleanly. Then restart it with the same `FAMILYCLAW_DATA_DIR`:

```bash
FAMILYCLAW_GATEWAY_ADDR=127.0.0.1:8787 \
FAMILYCLAW_CONFIG="$FC_PRIVATE_ROOT/familyclaw.toml" \
FAMILYCLAW_PROFILE_DIR="$FC_PRIVATE_ROOT/profiles" \
FAMILYCLAW_DATA_DIR="$FC_PRIVATE_ROOT/data" \
FAMILYCLAW_GATEWAY_TOKEN=local-demo-token \
cargo run -p familyclaw-gateway -- serve
```

Expected:

- Startup succeeds.
- Durable journal replay does not duplicate committed side effects.
- Memory/state loads from the same data directory.
- Torn trailing journal fragments, if present from a simulated crash, are healed on open rather than permanently corrupting later appends.

## 10. Confirm memory recall path

If a provider is configured, ask the agent to recall the checkpoint through the configured channel or supervised inject path.

If no provider is configured, use the benchmark and crash replay demos as the proof path:

```bash
bash scripts/demo-crash-replay.sh
cargo run -p familyclaw-bench --bin bench -- all
```

Expected:

- The generic proof path remains runnable without private provider keys.
- Full text recall requires a configured provider endpoint.

## 12. What this proves today

This demo proves:

- Layer B can stay outside the repository.
- The repo can be validated without private profiles.
- The living-feature matrix is explicit.
- Durable restart and replay behavior are release-critical.
- Gateway liveness/readiness are deployable.
- Supervised inbound can be protected with bearer auth.
- Per-message origin is part of the route contract.
- Benchmarks provide repeatable continuity proof.

## 13. What remains explicitly experimental

Keep these statements honest in release docs:

- Native support for any stale/quarantined feature is not release-supported until it compiles and is tested in CI.
- Hidden-state receive-side cognition transfer is a family-boundary decision and must not be implied as general production behavior unless explicitly implemented and reviewed.
- Channel adapters vary in maturity. Each adapter must document its own inbound, outbound, auth, and replay behavior.
- Production durability requires a real persistent `FAMILYCLAW_DATA_DIR` or external storage backend.

## 14. Pass criteria

The 11/10 demo passes when:

- Layer B audit passes.
- Default tests pass.
- Living-feature matrix passes.
- Clippy and formatting pass.
- Bench scorecard passes.
- Gateway starts.
- `/healthz` and `/readyz` respond.
- `/inject` rejects missing/wrong tokens and accepts the correct token.
- Origin-aware routing is observed or covered by tests.
- Restart does not corrupt durable state.
- No private data enters tracked files, logs, images, or generated artifacts.
